Add players, make teams, put people on them, see who has confirmed, appoint officials. Everything on it is one call each: tdc_league_season_entrants, tdc_league_season_teams, tdc_league_season_readiness and tdc_league_officials to read, and tdc_add_league_entrant / tdc_set_league_entrant / tdc_remove_league_entrant / tdc_create_team / tdc_update_team / tdc_delete_team / tdc_add_league_role / tdc_remove_league_role to change it. After every write everything is read again rather than patched here, because the server owns the answer. Only players with an account can be added: they have to confirm their own place, which a walk-in cannot do. Reached as /leagues/manage/?s=. {% endcomment %}
