Search, add, mark paid, confirm, seed, randomise. Everything on it is one call each: tdc_tournament_entrants to read the list, and tdc_add_entrant / tdc_set_entrant / tdc_remove_entrant / tdc_set_seeds to change it. After every write the list is read again rather than patched here, because the server owns the ordering. Reached as /tournaments/manage/?t=. {% endcomment %}
