Controls

Each slider sets its token on this page only, until a reload. To keep a value, set it on the main sandbox (Dots) and save it into variables.css.

Pick one to play it on repeat: a solo move for all four dots, or a group move back to back. Random: each dot its own solo moves, and a group every 2 to 5 seconds.

Failures

Each button makes one thing go wrong on the stage. The failure should show as "TDC (Error)" (on the dots' own line at the foot of the screen, or on this section's line when ticked below) and in the console with [Dots]; the target should still end right. When it is all over, the check below lists anything still marked by the dots.

    Page load

    Puts all twelve things on the stage back into loading, each for its own random time up to the network delay; about a quarter come back within 0.15 s and should show nothing. The dots go to the first one still loading, in the page's order, and fly on to the next as each comes in. Only the last is traced, raced and faded. Tap anything already back to see a tap take the dots.
