Redeem Codes

Redeem a code

For a player without the app open, such as a walk-in. A player can also redeem their own code from their profile.

Type at least 2 letters.

Generate codes

Up to 200 at a time.

New codes

These codes are shown once. They aren't stored anywhere as plain text, so if this list is lost, the credits it printed can no longer be redeemed.

Void a code

For a code that was printed in error or lost before use. Already-redeemed codes can't be voided.
